# 🧠 AI Idea Validator (Gemini API)

This module validates startup ideas using Google's Gemini API.

It analyzes an idea and provides:

- Feasibility Score
- Market Potential
- Competition Level
- Strengths & Weaknesses
- Suggestions for improvement
- Final Verdict

---

## 🚀 Features

- AI-powered startup evaluation
- Structured JSON output
- Competitor-aware validation
- Easy integration with FastAPI backend
